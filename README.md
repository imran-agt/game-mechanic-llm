## 📖 Overview

This is the **Ainsworth Game Technology (AGT)** private RAG platform. This tool has been customized to serve as a private, secure knowledge base for our Game Design, Mathematics, and Engineering teams.

It allows AGT staff to interact with proprietary game documentation, math models, and regulatory requirements (GLI/Jurisdictional) using advanced RAG (Retrieval-Augmented Generation) technology.

### 🛠️ Industry-Specific Features

- **Math Model Analysis:** Securely upload and query game math spreadsheets and logic documents.
- **Regulatory Compliance GPT:** Integrated knowledge of global gaming standards (NSW, North America, LATAM).
- **Ainsworth IP Security:** Configured for local-first or private cloud deployment to ensure no data leaks to public LLM training sets.
- **Branded Interface:** UI theme customized to match the Ainsworth corporate identity.
